# Learn365

个人学习博客（静态站点），含归档、分类、标签与站内搜索，收录 2021 年以来的学习笔记。

## 结构

- `index.html` — 首页
- `archives/` `categories/` `tags/` `page/` — 归档 / 分类 / 标签 / 分页
- `search.xml` — 站内搜索索引
- `css/` `js/` `images/` — 样式、脚本与图片资源
- `back_CNAME` — 自定义域名绑定记录

## 本地预览

纯静态文件，任意静态服务器即可运行：

```bash
python3 -m http.server 8000
```
